# Итоговое задание: антиспам-фильтр на NLP

**Дисциплина:** Применение ML в кибербезопасности
**Тема:** разработка модели распознавания спама + категоризация письма
**Код:** https://github.com/Andrey123654/antispam-ml
**Презентация:** `reports/Итоговое_задание_антиспам.pptx`

## Что сделано

| Этап задания | Результат |
|---|---|
| 1. Сбор и обработка данных | три независимых корпуса: SpamAssassin (6 155 писем), Ling-Spam (2 875), SpamBase (4 601, 57 табличных признаков) + 25 транзакционных писем; тест из задания (1 545) |
| 2. Обучение модели | TF-IDF по словам и символьным n-граммам + 94 числовых признака; 4 базовые модели и стекинг; 5-фолдовая кросс-валидация |
| 3. Упаковка | FastAPI + Docker (`antispam-service:1.0.0`, 796 МБ, healthcheck) |
| 4. Публикация | контейнер собран и запущен, эндпоинты проверены |
| Доп. задание | категоризация письма: 6 категорий + «прочее», macro-F1 = 0.723 |

## Ключевые метрики

| Оценка | F1 | Precision | Recall | Ложные срабатывания |
|---|---|---|---|---|
| Кросс-валидация (9 055 писем) | 0.977 | 0.980 | 0.975 | 46 (0.68 %) |
| Тест из задания (1 545) | 0.941 | 0.988 | 0.897 | 10 из 590 |
| Только невиданные письма (342) | 0.802 | 0.949 | 0.695 | 12 из 24 |
| SpamAssassin → Ling-Spam | 0.842 | 0.768 | 0.932 | — |

## Что важно знать проверяющему

1. **Тестовый набор на 78 % состоит из копий обучающих писем** (1 203 из 1 545 —
   точные копии писем SpamAssassin). Поэтому приведены две оценки: на всём тесте
   и только на письмах, не встречавшихся в обучении.
2. **Главный источник ложных срабатываний — транзакционные письма** (сброс пароля,
   подтверждение адреса, квитанции): лексически они похожи на фишинг. Добавление
   25 таких писем и признака доли кириллицы снизило FP на тесте с 17 до 10.
3. **Категории размечены слабо** — правилами по ключевым словам (правила приведены
   в `src/category.py`), поэтому macro-F1 характеризует воспроизведение правил,
   а не экспертную разметку.
4. **Язык:** корпуса англоязычные, в тесте есть русские письма — модель работает
   на них хуже, это подтверждено разбором ошибок.

## Воспроизведение

```bash
git clone https://github.com/Andrey123654/antispam-ml && cd antispam-ml
python -m venv .venv && .venv/bin/pip install -r requirements.txt
bash scripts/download_data.sh   # корпуса и тест из задания
bash run.sh                    # данные → обучение → категории → рисунки
docker build -t antispam-service:1.0.0 -f service/Dockerfile .
docker run -p 8000:8000 -e SPAM_THRESHOLD=0.80 antispam-service:1.0.0
```
